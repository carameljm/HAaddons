# Changelog

## 4.0.0
- Initiële Home Assistant Add-on release voor TREK
- Ondersteuning voor Home Assistant Ingress met directe zijbalkkoppeling
- Automatische SQLite persistentie via `/data` (geen dataverlies bij updates)
- Automatische 32-byte encryptiesleutelgeneratie en veilige opslag
- Volledige multi-arch ondersteuning (aarch64, amd64, armv7)
- Eerste beheerderaccount configuratie via `options.json`
- Nederlandse en Engelse vertalingen voor Home Assistant Supervisor UI
