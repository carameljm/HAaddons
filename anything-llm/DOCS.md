# AnythingLLM Home Assistant Add-on

A full-stack application that turns any document, resource, or content into context that any LLM can use as a reference during chatting.

## Configuration

The add-on uses `/config/anything-llm/storage` for persistent data. This can be backed up using standard Home Assistant backup tools.
